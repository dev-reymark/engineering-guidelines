# Documentation Rules

Maintain traceability:
Requirement → Finding → Decision → Prompt → Implementation → Test → Result

- Store major prompts under `docs/prompts/`.
- Store important decisions under `docs/decisions/`.
- Use stable finding IDs.
- Maintain required result documents.
- Update documentation when behavior or architecture materially changes.
- Never fabricate historical prompts or evidence.
- Never claim regulatory compliance without authoritative support.
