# Workflow — Audit

1. Define scope and forbidden changes.
2. Establish baseline verification.
3. Read relevant documentation.
4. Trace actual repository/runtime behavior.
5. Record evidence-backed findings with stable IDs.
6. Separate verified facts from recommendations.
7. For compliance, use current authoritative sources.
8. Build/update roadmap only after findings.
9. Verify no out-of-scope changes.
10. Document results and STOP.
