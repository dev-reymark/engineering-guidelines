# Workflow — New Project

1. Read `AGENTS.md` and `docs/ENGINEERING-STANDARD.md`.
2. Define objective, users, scope, constraints, and non-goals.
3. Research domain/regulatory requirements where needed.
4. Create/update PROJECT, REQUIREMENTS, and DOMAIN docs.
5. Design architecture, data model, and security model.
6. Identify high-risk workflows.
7. Create a phased roadmap.
8. Implement one approved phase at a time.
9. Verify, review the diff, document results, and STOP for approval.
