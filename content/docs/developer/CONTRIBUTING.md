# Contributing

**Status:** Draft

## Before Making Changes

Read `AGENTS.md`, the engineering standard, relevant requirements, architecture, ADRs, findings, and the active prompt.

## Scope Discipline

Implement only approved scope. Record unrelated discoveries as findings instead of silently expanding work.

## Code Quality

Follow project coding, architecture, database, security, testing, documentation, and UI rules.

## Verification

Run the project's required tests, type-check, lint, build, and applicable integration/security checks.

## Documentation Impact

Before completion ask:

> Does this change affect user-facing behavior, administration, onboarding, training, operations, support procedures, or developer setup?

If yes, update the relevant documentation.

If no, record:

`Documentation impact: None`

in the phase result where applicable.

## Completion

Review the complete diff, update traceability records, create/update the phase result, then stop at the phase boundary.
