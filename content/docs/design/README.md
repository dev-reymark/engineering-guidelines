# Design Documentation

This directory defines the project's UI/UX system.

Use these documents as the source of truth for visual and interaction consistency:

- `DESIGN-SYSTEM.md` — tokens, foundations, and component standards.
- `UI-GUIDELINES.md` — interface composition and component usage.
- `UX-GUIDELINES.md` — workflows, feedback, forms, destructive actions, and interaction behavior.
- `ACCESSIBILITY.md` — accessibility requirements.
- `RESPONSIVE-DESIGN.md` — responsive/adaptive behavior.

These are templates. Adapt them to the actual product rather than forcing one visual style on every project.
