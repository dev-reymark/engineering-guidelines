# Onboarding Guide

**Status:** Draft

## Goal

Help a new organization or user reach a correctly configured first successful workflow.

## Before You Start

List verified prerequisites.

## Setup Sequence

1. Account/access setup
2. Organization/workspace setup
3. Required configuration
4. User/role setup
5. Operational data setup
6. Verification
7. First real workflow

Adapt this sequence to the project.

## Owner / Administrator Checklist

- [ ] Required configuration completed
- [ ] Roles and permissions reviewed
- [ ] Required integrations verified
- [ ] Operational settings verified
- [ ] Staff/users trained where applicable
- [ ] First workflow tested
- [ ] Support/escalation path understood

## Role-Specific Onboarding

Add sections only for roles that actually exist.

## Production / Go-Live Conditions

Never state that regulatory, security, payment, fiscal, or other external approval is complete unless verified.
