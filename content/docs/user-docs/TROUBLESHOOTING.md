# Troubleshooting Guide

**Status:** Draft

Document verified troubleshooting procedures.

## Issue Template

### Symptom

What the user sees.

### Likely Causes

Only include supported causes.

### Safe Checks

Steps that do not risk data loss or security exposure.

### Resolution

Verified recovery procedure.

### Escalate When

State when the user should stop and contact an administrator/support/developer.

## Rules

- Never instruct users to bypass authorization or security controls.
- Never recommend destructive database actions as routine troubleshooting.
- Never expose secrets.
- Clearly warn before irreversible actions.
- Distinguish user-fixable problems from administrator/developer incidents.
