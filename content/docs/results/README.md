# Phase Results Registry

Result documents record what actually happened during execution.

Prompts describe instructions. Results describe reality.

## Registry

| Phase | Prompt | Status | Findings Addressed | Verification | Result Document |
|---|---|---|---|---|---|
| — | — | No phases executed yet | — | — | — |

## Result Requirements

Every material implementation/remediation phase must record:

- objective
- prompt ID
- findings/requirements addressed
- actual changes
- files changed
- migrations/schema impact
- security impact
- compliance impact where applicable
- tests added/changed
- commands run
- actual verification results
- diff review
- deviations from prompt
- new findings
- deferred work
- rollback/recovery notes where applicable
- acceptance criteria outcome
- final phase status

Do not claim a check passed unless it was actually run successfully.
