# Project Documentation

This directory is the engineering record for the project.

- `ENGINEERING-STANDARD.md` — reusable engineering and AI-agent rules.
- `project/` — what is being built, requirements, domain, roadmap.
- `architecture/` — architecture, data model, security, audits/remediation.
- `compliance/` — regulatory requirements, sources, gaps, roadmap when applicable.
- `prompts/` — exact major AI-agent execution prompts and registry.
- `decisions/` — Architecture/Compliance Decision Records (ADRs).
- `findings/` — reusable finding format and cross-domain findings when needed.
- `results/` — verified outcomes of implementation/remediation phases.
- `testing/` — test strategy and test matrix.
- `operations/` — deployment, environment, backup/recovery, and runbooks.

## Traceability

Important work should be traceable as:

`Requirement → Finding → Decision → Prompt → Implementation → Test → Result`

Do not treat prompts as proof of implementation, result documents as legal authority, or ADRs as substitutes for requirements.
