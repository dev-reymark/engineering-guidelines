# Changelog

## 1.1 — Scaffold v4.1

Added documentation lifecycle support:

- end-user guide
- administrator guide
- onboarding guide
- training guide
- FAQ
- troubleshooting guide
- developer getting-started documentation
- local development guide
- contributing guide
- user-documentation agent rule
- user-documentation workflow
- mandatory documentation-impact assessment in phase completion

The standard now treats user/training/support documentation as part of implementation completion when behavior changes.

## 1.0 — Scaffold v4

First frozen baseline of the reusable engineering scaffold.

Includes:
- engineering/project documentation
- architecture, security, database, and compliance structure
- AI agent rules and workflows
- design system, UI/UX, accessibility, and responsive standards
- prompt execution ledger
- centralized findings registry
- phase results registry
- audit/finding/result templates
- explicit end-to-end traceability
- production-readiness and verification workflows

Future changes should increment the standard version rather than silently replacing this baseline.
